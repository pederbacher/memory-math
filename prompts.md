## Generate the web application

There should be an overview page—spanning two pages—displaying a large table of all the cards; this could be implemented as a composite image (like a PNG file containing multiple smaller images).

It should also be possible to search through the text and mathematical content. A filter field—supporting regular expressions—would allow users to search within the card names and/or the text, displaying only the matching cards in the table.

Users should be able to create a collection by checking a box next to specific cards, adding them to that collection.

There should be a separate page for creating new cards, where users can input the mathematical expression, an explanation, and a link to Wikipedia.

Users must also specify the range for the x-axis used in the plot.

Each collection should include a description. It should be possible to print the collection across two pages, containing the table, the graph, and the explanation.

A QR code should be generated for each collection, allowing users to access it and explore further online.

It should be possible to download a collection in a format—such as a "Pixum" file—that makes it easy to order a physical copy.

There should also be a collection overview page where users can search through existing collections. From here, users can create a new collection by providing an ID, a name, and a description.

Users should be able to select a collection from the overview page;
once selected, they can add new cards to that specific collection.
